# Printing & PDF Output Documentation

## ID Card Physical Standard
- **Standard Dimensions:** 85.60 mm × 53.98 mm (CR80 Standard ID Card format).

## QuestPDF Integration
- Single and Bulk ID cards are rendered as vector PDF documents.
- Supports grid layout printing on standard A4 paper (2x4 or 2x5 cards per sheet).
- Supports direct Windows Printer dispatch via `System.Windows.Controls.PrintDialog`.
